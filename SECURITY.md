# Política de segurança

## Reportar uma vulnerabilidade

Este projeto usa o recurso de relato privado de vulnerabilidades do GitHub (private vulnerability reporting).

Para reportar, acesse a aba "Security" do repositório e clique em "Report a vulnerability". Não abra uma issue pública para falhas de segurança.

O relato é privado entre você e os mantenedores até que a correção seja publicada.

## Escopo

Descreva aqui, na primeira sessão, o que o projeto guarda e processa (dados pessoais, pagamento, nada sensível) e o que conta como falha de segurança para ele. Falhas em dependências e em configuração de build e publicação sempre estão no escopo.

## Segredos

Nenhum segredo é guardado no repositório. Se você encontrar uma chave, senha ou token exposto, reporte pelo mesmo canal privado.
