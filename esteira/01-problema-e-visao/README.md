# Etapa 1. Problema e visão

**Objetivo:** Impedir que o projeto resolva certo o problema errado.

| | |
|---|---|
| Entra | Entrevista com o dono (e o sócio, se houver). |
| Sai | `visao.md` com problema, quem usa, frase única, sinais de sucesso, riscos e o que acontece se falhar. |
| Quem decide | O dono aprova. Ponto de aprovação 1 de 3. |
| Roteiro do agente | [prompt.md](prompt.md) |

**Critério de aceite:** os campos do documento estão preenchidos de forma específica e o dono confirmou.
