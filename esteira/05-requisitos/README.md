# Etapa 5. Requisitos tirados da tela

**Objetivo:** Transformar as telas aprovadas em requisitos rastreáveis e validados.

| | |
|---|---|
| Entra | Telas aprovadas da etapa 4, `escopo.md`, `jornadas.md`. |
| Sai | `requisitos.md` (RF e RNF com fonte, prioridade, justificativa e situação) e a lista de pendentes e conflitos. |
| Quem decide | O agente escreve, o dono aprova a lista. |
| Roteiro do agente | [prompt.md](prompt.md) |

**Critério de aceite:** todo requisito tem fonte, prioridade e justificativa, passou no checklist de 7 critérios ou está pendente com motivo.

Regras que valem em toda etapa: [esteira/README.md](../README.md) e [principios-de-perguntas.md](../principios-de-perguntas.md). Decisão tomada aqui vira arquivo em [esteira/decisoes](../decisoes/README.md).
