# Etapa 3. Funcionalidades e corte do MVP

**Objetivo:** Levantar tudo o que o produto poderia ter e cortar para o que a primeira versão precisa.

| | |
|---|---|
| Entra | `visao.md` e `jornadas.md`. |
| Sai | `funcionalidades.md` (lista aprovada, por tema) e `escopo.md` (Agora, Depois, Nunca). |
| Quem decide | O agente propõe, o dono move itens de lista. Sem ponto de aprovação próprio. |
| Roteiro do agente | [prompt.md](prompt.md) |

**Critério de aceite:** a lista Agora tem só o essencial para cumprir a frase da visão e o dono aprovou as três listas.

Uma escala só: Agora, Depois, Nunca. Dentro do Agora, cada item diz se entra mantido, simplificado ou simulado.
