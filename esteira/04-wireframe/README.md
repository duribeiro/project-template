# Etapa 4. Wireframe da jornada

**Objetivo:** Desenhar as telas da jornada antes de levantar requisitos.

| | |
|---|---|
| Entra | `escopo.md` e `jornadas.md`. |
| Sai | Lista de telas, especificação de cada tela, desenhos aprovados e `regras-de-desenho.md`. |
| Quem decide | O dono aprova cada tela. Ponto de aprovação 2 de 3. |
| Roteiro do agente | [prompt.md](prompt.md) |

**Critério de aceite:** todas as telas têm especificação, desenho e veredito aprovado do dono.

Alta fidelidade (cores, fontes, imagens) pode ser uma sub-etapa, `04b-alta-fidelidade`, feita por fatia (uma seção ou página por vez) depois do wireframe aprovado.

Regras que valem em toda etapa: [esteira/README.md](../README.md) e [principios-de-perguntas.md](../principios-de-perguntas.md). Decisão tomada aqui vira arquivo em [esteira/decisoes](../decisoes/README.md).
